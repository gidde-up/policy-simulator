MANUAL SETUP INSTRUCTIONS
=========================

Open Command Prompt (cmd) and run these commands ONE BY ONE:

STEP 1 - Navigate to project:
-----------------------------
cd C:\Users\bernd\policy-simulator\backend

STEP 2 - Create Python virtual environment:
-------------------------------------------
python -m venv venv

STEP 3 - Activate virtual environment:
--------------------------------------
venv\Scripts\activate

STEP 4 - Install Python packages (this takes a minute):
-------------------------------------------------------
pip install -r requirements.txt

STEP 5 - Start the backend server:
----------------------------------
python -m uvicorn app.main:app --reload --port 8000

(Keep this window open! The server is running.)


NOW OPEN A SECOND Command Prompt window and run:
================================================

STEP 6 - Navigate to frontend:
------------------------------
cd C:\Users\bernd\policy-simulator\frontend

STEP 7 - Install npm packages:
------------------------------
npm install

STEP 8 - Start the frontend server:
-----------------------------------
npm run dev


STEP 9 - Open your browser:
---------------------------
Go to: http://localhost:5173


TO STOP: Press Ctrl+C in both terminal windows.
