# Employment multipliers: new (OECD ICIO 2025 pipeline) vs old (hardcoded, removed in Phase 2)

Old values were typed into source code and labelled 'OECD TiVA/ICIO 2023' (ZAF) or 'stylized' (TUN); the audit found no code deriving them from any dataset. New values are computed by this pipeline from OECD ICIO 2025 (year 2022, current USD) with employment from OECD TiM 2025/ILOSTAT. Old values claim reference year 2020; level differences therefore combine methodology and price-year effects.
